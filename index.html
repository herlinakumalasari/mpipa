Rubrik Keterampilan Proses Sains (Skala 1 - 4)

Aspek Keterampilan Skor 1 (Perlu Bimbingan) Skor 2 (Cukup) Skor 3 (Baik) Skor 4 (Sangat Baik)
1. Mengamati Hanya menyebutkan 1 objek tanpa ciri gerak. Menyebutkan perubahan posisi secara umum. Mendeskripsikan gerak benda di 2 permukaan. Mendeskripsikan perbedaan laju & hambatan permukaan secara rinci.
2. Bertanya & Prediksi Pertanyaan tidak berkaitan dengan topik gaya. Pertanyaan relevan namun prediksi tanpa alasan. Membuat prediksi logis mengenai gerak benda. Merumuskan pertanyaan ilmiah dan prediksi berbasis hubungan sebab-akibat.
3. Melakukan Percobaan Tidak mengikuti langkah kerja yang disiapkan. Melakukan percobaan dengan bantuan penuh guru. Melakukan percobaan mandiri dengan benar. Melakukan percobaan sistematis, teliti, dan mengutamakan keselamatan kerja.
4. Mengolah Data Data tabel kosong atau tidak sesuai. Mencatat data namun ada nilai yang tertukar. Mencatat seluruh data pengamatan dengan tepat. Mencatat data rapi serta membandingkan pola jarak tempuh antarpermukaan.
5. Menarik Kesimpulan Kesimpulan tidak menjawab masalah awal. Menyimpulkan tapi belum mengaitkan dengan bukti. Menyimpulkan pengaruh gaya terhadap gerak benda. Menyimpulkan secara tepat bahwa kekasaran permukaan memperbesar gaya gesek.
6. Mengomunikasikan Pasif dan enggan menyampaikan hasil. Menyampaikan hasil dengan membaca teks terbata-bata. Menyampaikan laporan dengan suara jelas dan runtut. Menyampaikan hasil dengan percaya diri, komunikatif, dan menjawab tanggapan teman.

Kode Google Apps Script (GAS) untuk Google Sheets

Salin kode di bawah ke Extensions > Apps Script pada Google Sheets Bapak/Ibu:

function doPost(e) {
  var lock = LockService.getScriptLock();
  lock.tryLock(10000);
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    // Pastikan Header Kolom Baris 1:
    // [Tanggal, Nama Siswa, Kelas, Gaya Diselidiki, Prediksi, Hasil Pengamatan, Kesimpulan, Skor Kuis, Nilai Keterampilan]
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        "Tanggal", "Nama Siswa", "Kelas", "Jenis Gaya",
        "Prediksi Siswa", "Hasil Pengamatan", "Kesimpulan",
        "Skor Kuis", "Catatan Refleksi"
      ]);
    }
    var data = JSON.parse(e.postData.contents);
    sheet.appendRow([
      new Date().toLocaleString("id-ID"),
      data.studentName || "Anonim",
      data.studentClass || "-",
      data.forceType || "Gaya Gesek",
      data.prediction || "-",
      data.observation || "-",
      data.conclusion || "-",
      data.quizScore || 0,
      data.reflection || "-"
    ]);
    return ContentService.createTextOutput(
      JSON.stringify({ "status": "success", "message": "Data berhasil disimpan!" })
    ).setMimeType(ContentService.MimeType.JSON);
  } catch (error) {
    return ContentService.createTextOutput(
      JSON.stringify({ "status": "error", "message": error.toString() })
    ).setMimeType(ContentService.MimeType.JSON);
  } finally {
    lock.releaseLock();
  }
}

Langkah Publikasi Apps Script:

  1. Klik tombol biru Deploy > New deployment.
  2. Pilih tipe Web app.
  3. Pada Who has access, pilih Anyone (Siapa saja).
  4. Klik Deploy, lalu salin URL Web App dan tempelkan pada kolom pengaturan di atas!
